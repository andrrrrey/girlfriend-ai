# Чек-лист тестирования — Girlfriend AI (роль: обычный пользователь)

> Тестировщик проходит весь путь от нового посетителя до активного пользователя.  
> Каждый пункт — конкретное действие. Результат: ✅ прошло / ❌ не прошло / ⚠️ замечание.

---

## 1. Первое знакомство с платформой

- [ ] Открой главную страницу сайта (`/`)
- [ ] Убедись, что страница загрузилась без ошибок (нет 500, нет белого экрана)
- [ ] Проверь, что карточки персонажей отображаются с аватарами и именами
- [ ] Попробуй поиск по персонажам — введи любое слово в поисковую строку
- [ ] Попробуй фильтрацию по тегам — кликни на один из доступных тегов
- [ ] Проверь пагинацию — листай страницы с персонажами вперёд и назад
- [ ] Наведи курсор на карточку персонажа — убедись, что hover-эффект работает
- [ ] Открой публичную галерею (`/gallery`) без авторизации
- [ ] Открой раздел Shorts (`/shorts`) без авторизации
- [ ] Попробуй открыть чужой публичный профиль (`/users/<nickname>`)
- [ ] Убедись, что при попытке перейти в чат без авторизации — редиректит на `/login`

---

## 2. Регистрация

- [ ] Открой страницу регистрации (`/register`)
- [ ] Попробуй зарегистрироваться с **пустыми полями** — убедись, что форма показывает ошибки валидации
- [ ] Попробуй ввести **невалидный email** (например, `test@`) — должна быть ошибка
- [ ] Попробуй ввести **пароль короче 6 символов** — должна быть ошибка
- [ ] Попробуй ввести **уже зарегистрированный email** — должна быть ошибка "пользователь уже существует"
- [ ] Заполни форму корректными данными (валидный email + пароль ≥ 6 символов)
- [ ] Пройди CAPTCHA (Turnstile)
- [ ] Нажми кнопку регистрации — убедись, что аккаунт создан и тебя перенаправило
- [ ] Проверь, что на почту пришло письмо с подтверждением email

---

## 3. Подтверждение email

- [ ] Открой письмо с подтверждением в почтовом клиенте
- [ ] Кликни по ссылке верификации в письме
- [ ] Убедись, что сайт показывает сообщение об успешном подтверждении
- [ ] Убедись, что повторный переход по той же ссылке — не ломает страницу (должна быть понятная ошибка или редирект)
- [ ] Проверь: если письмо не пришло — нажми кнопку "Отправить повторно" (`/resend-verification`)

---

## 4. Вход в аккаунт

- [ ] Открой страницу входа (`/login`)
- [ ] Попробуй войти с **неверным паролем** — должна быть ошибка
- [ ] Попробуй войти с **несуществующим email** — должна быть ошибка
- [ ] Войди с правильными учётными данными
- [ ] Пройди CAPTCHA
- [ ] Убедись, что после входа тебя перенаправило на главную / дашборд
- [ ] Убедись, что UI сменился на "авторизованное состояние" (аватар/меню пользователя)

---

## 5. Восстановление пароля

- [ ] Открой страницу восстановления (`/forgot-password`)
- [ ] Введи **незарегистрированный email** — должна быть понятная ошибка или нейтральное сообщение
- [ ] Введи свой **реальный email** — нажми "Отправить ссылку"
- [ ] Открой письмо со ссылкой сброса пароля
- [ ] Перейди по ссылке (`/reset-password?token=...`)
- [ ] Введи новый пароль (валидный) — нажми "Сохранить"
- [ ] Убедись, что ты вошёл с новым паролем
- [ ] Убедись, что **старый пароль** больше не работает

---

## 6. Профиль пользователя

- [ ] Открой страницу профиля (`/profile`)
- [ ] Измени **никнейм** — сохрани — обнови страницу — убедись, что изменение сохранилось
- [ ] Проверь никнейм, который уже занят — должна быть ошибка "никнейм занят"
- [ ] Загрузи **аватар** — убедись, что фото сохранилось и отображается
- [ ] Смени **язык интерфейса** — убедись, что настройка сохранилась
- [ ] Добавь ссылки на социальные сети (VK / Instagram / X) — сохрани
- [ ] Обнови страницу и убедись, что ссылки не исчезли
- [ ] Удали одну из социальных ссылок — убедись, что удалилась
- [ ] Смени пароль через форму в профиле — введи старый и новый пароль

---

## 7. Публичный профиль и социальные функции

- [ ] Открой свой публичный профиль (`/users/<твой-никнейм>`)
- [ ] Убедись, что отображаются: никнейм, аватар, количество подписчиков
- [ ] Открой профиль **другого пользователя**
- [ ] Нажми кнопку "Подписаться" — убедись, что счётчик подписчиков вырос
- [ ] Нажми кнопку "Отписаться" — убедись, что счётчик уменьшился

---

## 8. Список персонажей и карточка персонажа

- [ ] Вернись на главную страницу (`/`)
- [ ] Кликни на карточку персонажа — убедись, что открывается детальная страница или модалка
- [ ] Поставь лайк персонажу — убедись, что счётчик обновился
- [ ] Сними лайк — убедись, что счётчик уменьшился
- [ ] Оставь **комментарий** к персонажу
- [ ] Убедись, что комментарий появился в списке
- [ ] Поставь лайк на чужой комментарий
- [ ] Удали свой комментарий — убедись, что он исчез

---

## 9. Чат с персонажем

- [ ] Открой раздел чатов (`/chat`)
- [ ] Создай **новый чат** с одним из персонажей
- [ ] Убедись, что чат появился в боковой панели
- [ ] Напиши первое сообщение и отправь
- [ ] Убедись, что ответ персонажа приходит в режиме **стриминга** (текст появляется постепенно)
- [ ] Отправь ещё 2–3 сообщения — убедись, что диалог продолжается корректно
- [ ] Нажми **"Скопировать"** сообщение персонажа — убедись, что текст скопировался в буфер
- [ ] Нажми **"Регенерировать"** ответ — убедись, что пришёл новый ответ
- [ ] **Отредактируй** своё отправленное сообщение — убедись, что последующие сообщения пересчитались/удалились и пришёл новый ответ
- [ ] **Удали** одно из сообщений — убедись, что оно исчезло
- [ ] Создай **второй чат** с другим персонажем — убедись, что чаты изолированы
- [ ] Переключись между чатами — убедись, что история каждого сохранена
- [ ] Переименуй чат — убедись, что имя сохранилось
- [ ] Удали один из чатов — убедись, что он пропал из списка

---

## 10. Голосовые функции (только для платных пользователей)

> Если аккаунт бесплатный — проверь, что появляется сообщение о блокировке и иконка замка.

- [ ] Нажми кнопку **записи голосового сообщения** в чате
- [ ] Если аккаунт бесплатный — убедись, что функция заблокирована с понятным сообщением (403 / баннер Premium)
- [ ] (Платный аккаунт) Запиши голосовое сообщение — убедись, что оно отправилось и транскрибировалось
- [ ] (Платный аккаунт) Нажми кнопку воспроизведения голосового ответа персонажа (TTS) — убедись, что аудио воспроизвелось

---

## 11. Генерация изображений

- [ ] Открой страницу генерации (`/generation`)
- [ ] Выбери **персонажа** из выпадающего списка
- [ ] Выбери **сцену** (Scene)
- [ ] Выбери **позу** (Pose)
- [ ] Выбери **внешность** (Appearance)
- [ ] Выбери **угол камеры** (Camera)
- [ ] Нажми кнопку **"Генерировать"**
- [ ] Убедись, что появился индикатор загрузки / статус задачи
- [ ] Дождись завершения генерации — убедись, что изображение появилось
- [ ] Убедись, что изображение добавилось в **историю генераций**
- [ ] Открой **историю** — убедись, что предыдущие генерации видны
- [ ] Попробуй удалить одну из генераций — убедись, что она исчезла
- [ ] Открой **галерею** (`/gallery`) — убедись, что публичные генерации видны
- [ ] Поставь лайк на изображение в галерее

---

## 12. Раздел Shorts (короткие видео)

- [ ] Открой раздел Shorts (`/shorts`)
- [ ] Убедись, что видео-контент отображается (или есть пустое состояние, если контента нет)
- [ ] Поставь лайк на шорт (если есть контент)
- [ ] Убедись, что счётчик лайков обновился

---

## 13. Мой AI (создание своего персонажа)

- [ ] Открой раздел "Мой AI" (`/my-ai`)
- [ ] Нажми "Создать нового персонажа"
- [ ] Заполни обязательные поля (имя, системный промпт / описание)
- [ ] Сохрани персонажа — убедись, что он появился в списке
- [ ] Начни чат с **созданным персонажем**
- [ ] Убедись, что персонаж отвечает согласно заданному описанию
- [ ] Отредактируй персонажа — измени имя — сохрани — убедись, что изменение отразилось
- [ ] Удали персонажа — убедись, что он пропал из списка

---

## 14. Лимиты бесплатного аккаунта

- [ ] Отправь **20 сообщений** в чате (лимит бесплатного плана)
- [ ] Убедись, что на 21-м сообщении пришла ошибка о превышении лимита (HTTP 429 / UI-уведомление)
- [ ] Убедись, что в UI есть **счётчик оставшихся сообщений** или информация о лимите
- [ ] Убедись, что в разделе голоса/TTS/STT отображается **баннер Premium** или иконка замка

---

## 15. Подписка (Subscription)

- [ ] Открой раздел подписки в профиле (`/profile` → вкладка Subscription)
- [ ] Убедись, что текущий статус подписки отображается корректно (Free / Premium)
- [ ] Проверь наличие информации о преимуществах платного плана

---

## 16. Выход из аккаунта

- [ ] Открой меню пользователя
- [ ] Нажми "Выйти"
- [ ] Убедись, что тебя перенаправило на главную / страницу входа
- [ ] Убедись, что при попытке открыть `/chat` — редиректит на `/login`
- [ ] Убедись, что токены очищены (localStorage пустой по ключам auth)

---

## 17. Граничные случаи и UX

- [ ] Попробуй отправить **пустое сообщение** в чате — кнопка отправки должна быть неактивна
- [ ] Попробуй **очень длинное сообщение** (1000+ символов) — убедись, что оно отправляется или есть понятное ограничение
- [ ] Отключи интернет во время стриминга ответа — убедись, что нет бесконечного лоадера
- [ ] Открой сайт в **мобильном браузере** (или DevTools → мобильный режим) — проверь адаптивность ключевых страниц
- [ ] Попробуй открыть несколько вкладок с чатом одновременно — убедись, что нет конфликтов
- [ ] Обнови страницу посередине генерации изображения — убедись, что задача не зависает навсегда
